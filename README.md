# Kalp Oluşturma

Bu proje, Python'un `turtle` kütüphanesini kullanarak matematiksel denklemlerle dinamik ve akışkan bir kalp animasyonu oluşturur. Siyah arka plan üzerinde merkeze bağlı çizgilerle yavaşça şekillenen mavi bir kalp çizimi sunar.

## ✨ Özellikler
- **Parametrik Çizim:** Kalp formu, trigonometrik fonksiyonlar kullanılarak hassas bir şekilde hesaplanır.
- **Görsel Efekt:** Çizgilerin sürekli başlangıç noktasına dönmesiyle derinlik algısı yaratan bir animasyon oluşur.
- **Hız:** `speed(1000)` ayarı ile çizgiler hızlı hareket ederken genel formun oluşumu izlenebilir.

## 🛠️ Kullanılan Teknolojiler
- **Python 3**
- **Turtle Graphics**
- **Math Module**
